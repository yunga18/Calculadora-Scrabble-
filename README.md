# Calculadora de Scrabble

Marcador en español, adaptado a celulares, sin dependencias ni servicios de pago.

## Cómo jugar

1. Escribe los nombres de 2 a 8 jugadores.
2. Ordena los turnos con las flechas.
3. Introduce los puntos de cada jugada. El turno avanza automáticamente; pasar registra 0 puntos.
4. Marca la ronda actual como final. Al completar el último turno se abre el recuento. También puedes terminar inmediatamente.
5. Introduce los puntos que pierde cada jugador. La aplicación los resta, ordena la clasificación y muestra el ganador o empate.

Los puntos del historial se pueden corregir antes de cerrar el resultado. Puedes deshacer la última jugada, revisar los descuentos o empezar otra partida.

La partida se guarda automáticamente en el navegador del dispositivo. No se sincroniza entre dispositivos. Borrar los datos del navegador elimina la partida.

## Publicación

En el repositorio, abre **Settings → Pages**. Selecciona **Deploy from a branch**, rama **main**, carpeta **/(root)** y pulsa **Save**.

Dirección prevista después de activar GitHub Pages:
https://yunga18.github.io/Calculadora-Scrabble-/

También puedes abrir `index.html` directamente en tu navegador. El marcador usa los puntos introducidos manualmente; no calcula el valor de las palabras ni aplica bonificaciones automáticamente.
